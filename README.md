# おきなわこども選挙 2026

## こどもの、こどもによる、こどものための選挙

おきなわこども選挙は、沖縄県知事選挙と同じ時期に、18歳未満の子どもたちが参加する模擬選挙です。

候補者の考えを知り、自分で考えて一票を投じることを通して、政治や地域の未来を「自分のこと」として考える機会をつくります。子どもたちの投票は実際の選挙結果には反映されませんが、子どもたちの声や投票結果は、地域や政治に届けていきます。

## おきなわこども選挙の流れ

1. **聞く** — 沖縄の未来について聞きたいことを子どもたちが考え、候補者へ質問します。
2. **選ぶ** — 候補者の回答を見比べ、自分の考えで未来のリーダーを選びます。
3. **届ける** — 投票結果と子どもたちの声を、地域や政治に届けます。

## 2026年の開催予定

- **7月25日**：質問づくりワークショップを開催
- **8月27日以降**：候補者の回答動画を準備ができ次第公開
- **9月12日（土）11:00〜18:00**：こども選挙の投票（沖縄県知事選挙の期日前投票最終日）

沖縄県知事選挙の投開票日は、翌日の**9月13日（日）**です。

投票会場は、サンエー 浦添西海岸パルコシティ4階A区画です。対象年齢、居住要件、申込方法など、そのほかの詳しい参加情報は、決まり次第、公式サイトでお知らせします。

## これまでの活動

2026年7月25日、浦添市で小学生から高校生まで10人が参加する質問づくりワークショップを開催しました。子どもの権利と選挙について学び、絵本を使った模擬投票を体験したあと、沖縄県知事選挙の候補者へ届ける質問をみんなで考えました。

公式サイトでは、絵本『どうぶつせんきょ』（ほるぷ出版）を使った「読む・選ぶ・話す」の学び方も紹介しています。選挙やイベントがない時期にも、家庭・学校・地域でまちのことを話し始めるための学びのツールです。

こども選挙は全国20箇所以上で開催され、沖縄県は今回初の開催です。運営は、全国のネットワークに参加する「おきなわこども選挙実行委員会」が担います。

## 公平で安全なこども選挙のために

おきなわこども選挙は、特定の政党や候補者を支持・推薦する活動ではありません。

- すべての候補者に同じ質問・回答時間・撮影条件を用意します。
- 候補者の掲載順には中立的な基準を設けます。
- 実際の選挙が終わる前に、こども選挙の投票結果を公表しません。
- 子どもの写真・動画は、本人と保護者の同意範囲で掲載します。
- 誰に投票したかを言う必要はありません。
